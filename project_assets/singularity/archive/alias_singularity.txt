####### Build and test

To convert the provided Singularity definition file into a Singularity container and build it, follow these steps:

---

### **Step 1: Save the Definition File**
Save the generated definition file as `Singularity.def` in your working directory.

---

### **Step 2: Build the Singularity Container**
Run the following command in your terminal to build the container from the definition file:

```bash
sudo singularity build ros2_acados.sif Singularity.def
```

**Explanation:**
- `sudo`: Required for full system privileges during container creation.
- `singularity build`: Command to build the container.
- `ros2_acados.sif`: The name of the output container file (`.sif` stands for Singularity Image Format).
- `Singularity.def`: The name of the definition file.

---

### **Step 3: Verify the Container Build**
After the build completes, you can verify the container and test it:

```bash
singularity test ros2_acados.sif
```

This will run the `%test` section of your definition file, confirming that ROS, ACADOS, CasADi, and the `gym-pybullet-drones` library are installed correctly.

---

### **Step 4: Run the Singularity Container**
You can start the container and access its shell:

```bash
singularity shell ros2_acados.sif
```

or run a command inside the container directly:

```bash
singularity exec ros2_acados.sif python3 -c "import casadi; import acados_template; import gym; print('Container is ready!')"
```

---

### **Step 5: Run a ROS 2 Node Inside the Container**
To run a ROS 2 node from within the container:

```bash
singularity exec ros2_acados.sif ros2 run <package_name> <node_name>
```

---

### **Optional: Build in a Writable Sandbox Mode (For Development)**
If you need a writable container for ongoing development:

```bash
sudo singularity build --sandbox ros2_acados_sandbox Singularity.def
singularity shell --writable ros2_acados_sandbox
```
